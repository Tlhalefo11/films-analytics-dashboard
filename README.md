# Films Analytics Dashboard 

An interactive Power BI data visualization project exploring global film performance, looking into box office revenues, production budgets, genre distribution, and key cast and director metrics.

## Built With
* **Power BI (`.pbix`)** – Data modeling, DAX measures, and interactive visual layouts.
* **Python / Pandas** – Data cleaning and preprocessing.

## Repository Contents
* `Movies.csv`: The cleaned dataset containing movie titles, release dates, genres, budgets, revenues, and cast/director lists.
* `FILMS DASHBOARD.pbix`: The source Power BI project file.
* `FILMS DASHBOARD.pdf`: A static visual export/preview of the dashboard pages.

## Key Features & Insights
* **Financial Performance:** Tracks budget vs. box office revenue across different film genres.
* **Director & Cast Impact:** Visualizes the most recurring directors and top-billed cast members.
* **Release Trends:** Breaks down film releases across timelines.
